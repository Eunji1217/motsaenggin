# 못생긴놈들 글자나 맞춰라

**놀러 오세요 → https://eunji1217.github.io/motsaenggin/**

한글 낱말을 **기본 자모 24개**로 쪼개어 다섯 번 안에 맞히는 퍼즐.
(꼬들·Wordle 계열, 숫자야구와 같은 힌트 구조)

## 규칙

- 힌트는 **자모가 몇 칸인지**뿐. 글자 수는 알려주지 않습니다
- 겹자모는 풀어서 셉니다. `ㅐ = ㅏ+ㅣ`, `ㄲ = ㄱ+ㄱ`, `ㅘ = ㅗ+ㅏ`, `ㅄ = ㅂ+ㅅ`
- 그래서 `번개`도 `박쥐`도 `소나기`도 전부 **6칸**이고, 같은 판에 들어갑니다
- 🟩 자리까지 정확 / 🟨 낱말엔 있지만 다른 자리 / ⬛ 없는 자모
- 낱말 **353,399개**가 입력으로 인정됩니다

## 두 가지 방식

| | 오늘의 낱말 | 무한 연습 |
| --- | --- | --- |
| 출제 | 하루 한 문제, 모두 같은 낱말 (KST 자정에 교체) | 계속 새 낱말 |
| 중복 | — | **한 번 깬 낱말은 다시 안 나옴** |
| 순위 | 오늘 순위 · 누적 순위 | 깬 낱말 개수 순위 |
| 공유 | 이모지 결과 복사 | — |

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 마크업 + 스타일 (원고지 모티프, 라이트/다크) |
| `game.js` | 자모 분해, 채점, 자판, 두 모드, 기록·공유 |
| `words.js` | 출제 후보 640개 — 누구나 아는 낱말 (2~3글자) |
| `dict/N.txt` | 입력 허용 사전, 자모 N칸짜리. 한 줄에 한 낱말 |
| `config.js` | 순위표 API 주소. 비우면 순위 기능이 조용히 숨습니다 |
| `worker/` | 순위표 API (Cloudflare Worker + KV) |
| `og.png` · `icon.svg` | 링크 미리보기 카드, 파비콘 |
| `tools/build-dict.cjs` | `dict/*.txt` + `worker/src/answers.js` 생성기 |
| `tools/make-og.cjs` | `og.png` 생성기 (zlib 만으로 PNG 를 직접 씁니다) |

빌드 도구도 프레임워크도 없습니다. `dict/` 를 `fetch` 하므로 파일을 직접 여는 대신
`npx serve` 같은 걸로 띄우면 로컬에서도 그대로 돌아갑니다.

## 배포

`main` 브랜치 루트를 GitHub Pages 가 그대로 서비스합니다.
고치고 `git push` 하면 1분쯤 뒤 반영됩니다.

## 순위표

게임은 서버 없이도 완전히 돌아갑니다. 순위표는 얹는 기능입니다.

| 엔드포인트 | 하는 일 |
| --- | --- |
| `POST /score` | 오늘의 낱말 기록 접수 |
| `POST /clear` | 무한 연습에서 낱말 하나를 깼다고 알림 |
| `GET /progress` | 그 닉네임이 깬 낱말 번호들 (새 기기에서 진도 이어받기) |
| `GET /board` | 오늘 순위 + 누적 순위 + 깬 낱말 순위 |

**제출된 기록은 서버가 그 정답으로 다시 채점합니다.** 자모 길이가 안 맞거나,
중간에 정답을 맞히고 더 친 척했거나, 아직 안 끝난 판은 거부됩니다.
닉네임은 기기마다 만든 임의의 열쇠와 묶여서 남이 같은 이름으로 올릴 수 없습니다.
KV 는 키 메타데이터에 요약을 담아 `list()` 한 번으로 전체 순위를 읽습니다.

```bash
node worker/test.mjs                        # KV 를 흉내 내어 배포 없이 로직 검증 (22개)

npx wrangler login                          # 최초 1회
cd worker
npx wrangler kv namespace create SCORES     # 나온 id 를 wrangler.toml 에 적기
npx wrangler deploy                         # 주소를 config.js 의 BOARD_API 에 적기
```

### 알아둘 것

- **부정 방지에 한계가 있습니다.** 재채점으로 앞뒤 안 맞는 기록은 막지만,
  정답이 `words.js` 안에 있어서 소스를 읽을 줄 아는 사람은 미리 답을 알 수 있습니다.
  친구들끼리 하는 판을 전제로 한 수준입니다. 정말 막으려면 채점을 서버로 옮겨야 합니다
  (정답을 브라우저에 아예 안 내려보내기).
- **낱말 번호는 정렬한 `ANSWERS` 의 위치입니다.** `words.js` 중간에 낱말을 끼워 넣으면
  번호가 밀려서 이미 저장된 진도가 다른 낱말을 가리킵니다. **뒤에 덧붙이기만** 하세요.
- 닉네임을 정하기 전에 깬 낱말은 서버 집계에 안 들어갑니다 (그 판 하나는 들어갑니다).

## 조작

- 화면 자판 클릭, 또는 **두벌식 그대로 타이핑** (영문 입력 상태에서도 `Q`→`ㅂ` 식으로 동작)
- `Enter` 입력, `Backspace` 지우기
- 기록은 이 브라우저 `localStorage` 에 저장되고, 닉네임을 정하면 깬 낱말만 서버에도 쌓입니다

## 사전

[acidsound/korean_wordlist](https://github.com/acidsound/korean_wordlist) 에서
순한글 낱말(1~6음절)을 추려 **자모 길이별로** 나눈 것입니다.
힌트가 "자모 몇 칸"이므로 글자 수로는 나눌 이유가 없습니다.
게임은 그날 필요한 길이 파일 하나만 내려받습니다.

| 자모 | 낱말 수 | | 자모 | 낱말 수 |
| --- | ---: | --- | --- | ---: |
| 4칸 | 4,487 | | 8칸 | 48,252 |
| 5칸 | 24,094 | | 9칸 | 46,721 |
| 6칸 | 44,986 | | 10칸 | 37,702 |
| 7칸 | 32,754 | | | |

```bash
node tools/build-dict.cjs
```

출제 후보를 늘리려면 `words.js` 의 `ANSWERS_RAW` **맨 뒤에** 낱말을 띄어쓰기로 붙이고
다시 돌리면 됩니다 (정답을 입력도 할 수 있도록 사전에 자동으로 합쳐집니다).
